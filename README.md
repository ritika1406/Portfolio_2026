# Ritika Tiwari — Editorial Portfolio

A Vite + React redesign of the supplied portfolio. Includes six original project concepts, responsive layout, category filters, project detail dialogs, navigation, and contact actions.

## Run

```bash
npm install
npm run dev
npm run build
```

## Before publishing

1. Open `src/main.jsx` and update `contact.email`, `contact.linkedin`, and `contact.github`.
2. Add verified `links.demo` and `links.github` URLs to each project as available.
3. Review every project note against your actual work. The supplied portfolio included draft descriptions, so this redesign intentionally avoids invented metrics and specific unverified implementation details.
4. Replace the conceptual CSS project visuals with genuine screenshots if available.

The portfolio has no backend requirement. `vercel.json` includes a single-page app rewrite for Vercel.
